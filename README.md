# ToDo List

### Веб-приложение  "ToDo List", разработанное с использованием современных технологий:
- Vue 3 (Composition API, <*script setup*>)
- TypeScript
- Vite
- Pinia
- CSS

### Приложение представляет собой SPA (Single Page Application), в котором пользователь может управлять своими задачами.

### Основные задачи:
1) Добавление задач:
    - Пользователь может добавлять новые задачи.
    - Реализована базовая валидация: запрет добавления пустых задач.

2) Удаление задач:
    - Задачи можно удалять. Удаленные задачи перемещаются в отдельный список.

3) Отметка задач как выполненных:
    - Пользователь может отмечать задачи как выполненные или снимать отметку.

4) Фильтрация задач (переключение между вкладками):

    - Все — отображаются все задачи.
    - Выполненные — отображаются только выполненные задачи.
    - Невыполненные — отображаются только невыполненные задачи.

5) Редактирование задач:
    - Пользователь может редактировать задачи

### Технологии и инструменты:
1) **Vue 3**:
    - Использован Composition API с синтаксисом <*script setup*> для более удобной и читаемой организации кода.

2) **TypeScript**:
    - Для типизации данных и повышения надежности кода.

3) **Vite**:
    - Современный инструмент для сборки и разработки, обеспечивающий высокую производительность.

4) **Pinia**:
    - Управление состоянием приложения. Использован вместо Vuex для более простого и гибкого API.

5) **CSS**:
    - Для стилизации компонентов и создания приятного интерфейса


### Структура проекта
- src/components/:
    - TaskInput.vue — компонент для ввода новых задач.
    - TaskList.vue — компонент для отображения списка задач.
    - TaskItem.vue — компонент для отображения отдельной задачи.
- src/stores/:
    - todoStore.ts — хранилище Pinia для управления состоянием задач (добавление, удаление, фильтрация).
- src/App.vue:
    - Корневой компонент приложения, который объединяет все остальные компоненты.
- src/types/:
    - task.d.ts - структура интерфейса Task(для описания структуры объекта)
- src:
    - styles.css - стилизация


### Как это работает: 
1) Хранилище (Pinia)
В todoStore.ts реализовано управление состоянием задач:
- Состояние:
    - tasks — список активных задач.
    - deletedTasks — список удаленных задач.
    - filter — текущий фильтр (all, completed, incomplete).
- Действия:
    - addTask — добавление новой задачи.
    - removeTask — удаление задачи.
    - toggleTask — переключение статуса задачи (выполнена/не выполнена).
    - setFilter — установка текущего фильтра.
- Геттеры:
    - filteredTasks — возвращает отфильтрованный список задач в зависимости от выбранного фильтра.

2) Компоненты: 
- TaskInput.vue:
    - Отвечает за ввод новой задачи и вызов метода addTask из хранилища.
- TaskList.vue:
    - Отображает список задач, используя геттер filteredTasks из хранилища.
- TaskItem.vue:
    - Отображает отдельную задачу и предоставляет кнопки для удаления и переключения статуса.


### Анимации
Для улучшения пользовательского опыта реализованы простые анимации:
- Появление новых задач.
- Удаление задач с плавным исчезновением.
- Запрет добавления пустых задач.

### Установка и запуск
1) Клонируйте репозиторий:

- >git clone git@github.com:An-art14/vue-todolist.git
- >cd vue-todolist

2) Установите зависимости:

- >npm install

3) Запустите проект в режиме разработки:
- >npm run dev

4) Соберите проект для production:
- >npm run build
